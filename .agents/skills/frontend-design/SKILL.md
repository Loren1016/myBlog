# Polene Paris 风格前端

以克制为前提进行设计和实现。页面的高级感应主要来自比例、留白、材质感、图片裁切、排版秩序和细节控制，而不是堆砌装饰。

不要直接复制品牌资产、商品名称、图像素材或现成版式。应当提炼气质，转化为原创页面。

## 核心原则

按以下顺序决策：

1. 先用留白建立品牌感。
2. 先考虑形体，再考虑装饰。
3. 让图片和材质细节承担情绪表达。
4. 用有编辑感的字体对比建立层级：展示字体精致，界面字体克制。
5. 动效尽量慢、柔和、低存在感。
6. 宁可元素更少，也要对齐更准、节奏更稳。

## 视觉语言

整体方向是“安静的高级感”，不是“张扬的奢华感”。

- 使用暖中性色，不使用高饱和主色主导页面。
- 优先考虑奶油白、粉笔灰、沙色、驼色、灰褐色、可可色、炭灰、雾橄榄等颜色。
- 黑色只作为文字、细线、重点轮廓的精确色，不作为页面情绪主色。
- 造型应偏向圆润、折叠、包裹、嵌套、偏移、非对称，以呼应皮革、布料、褶皱和雕塑轮廓。
- 边框尽量细，阴影尽量少。层次主要来自裁切、叠放、明度差和留白。
- 少用强烈渐变。如果使用，必须非常轻，像空气、纸面或光晕，而不是科技面板。

推荐色板：

```css
:root {
  --bg: #f6f1ea;
  --surface: #fbf7f2;
  --surface-2: #efe7dc;
  --text: #191714;
  --muted: #6f675f;
  --line: rgba(25, 23, 20, 0.12);
  --accent: #9f7f5d;
  --accent-deep: #6a4f37;
  --olive: #7a7a68;
}
```

## 字体与排版

用层级差而不是字重堆叠来制造气质。

- 主视觉标题、章节标题、引言句优先使用优雅衬线体或高对比展示字体。
- 导航、按钮、标签、筛选、辅助信息、正文优先使用干净克制的无衬线字体。
- 正文不宜过大，但要给足行高。
- 优先使用正常大小写或标题式大小写，避免大片攻击性的全大写。
- 标题换行要有造型感，看起来像经过设计，而不是自然折行。

推荐搭配方向：

- 展示字体：`Cormorant Garamond`、`Bodoni Moda`、接近 `Canela` 气质的替代字体、接近 `Ivy Presto` 气质的替代字体
- 界面与正文字体：接近 `Suisse Intl`、`Neue Haas Grotesk` 的风格，或 `General Sans`；`Inter` 仅作为兜底

字号节奏：

- 主视觉标题：`clamp(3rem, 7vw, 6.5rem)`
- 章节标题：`clamp(1.8rem, 3vw, 3rem)`
- 正文：`0.98rem` 到 `1.05rem`
- 辅助文字：`0.75rem` 到 `0.82rem`，字距 `0.08em` 到 `0.14em`

## 布局系统

页面需要“会呼吸”的空间感。

- 优先使用偏编辑设计的非对称构图，而不是完全居中的 SaaS 模板块。
- 大图区域后面接紧凑文字组，会比平均切块更有高级感。
- 全幅图片区和受控内容容器要交替出现。
- 栅格保持简单：桌面端 12 列，平板 6 列，移动端 4 列。
- 纵向节奏要大方，每个 section 像展陈单元而不是信息卡片堆。
- 允许一句短句单独占据一整个留白区。

间距建议：

- section 上下间距：`clamp(4rem, 8vw, 9rem)`
- 内容组 gap：`clamp(1rem, 2vw, 2rem)`
- 紧凑文字堆叠：`0.4rem` 到 `0.8rem`
- 图片到文字的大间距：`clamp(1.5rem, 3vw, 3.5rem)`

## 图片方向

图片是主叙事者，不是装饰附件。

- 使用光线干净、布景克制、调性统一的图片。
- 优先近景裁切、材质细节、曲线轮廓、负空间。
- 背景偏向灰泥、亚麻、石材、纸张、皮革、雾景、低对比自然环境。
- 比起热闹的生活方式照片，更偏静止、定格、雕塑化的画面。
- 商品图应像艺术品陈列，不像目录页堆货。
- 图片序列最好在“细节、轮廓、尺度关系”之间切换。

## 组件规则

### 顶部导航

- 导航要薄、静、精确。
- 减少视觉噪音，只保留必要分隔和排版秩序。
- 优先文本导航，不要充满存在感的实心胶囊按钮。
- 悬停反馈要轻，例如透明度变化、细下划线、色温轻微变化。

### 首屏 Hero

- 用一张强图或一组图像加一个有雕塑感的大标题开场。
- CTA 数量尽量少，最好一个主动作加一个次动作。
- 首屏不要塞满 badge、信任图标、促销标签或密集文案。

### 卡片

- 避免通用仪表盘式卡片。
- 采用图片主导的小面板，配简洁标题、短说明、精细元信息。
- 卡片底色尽量贴近页面底色，除非对比本身是叙事需要。

### 按钮与链接

- 优先文字按钮、描边按钮或柔和填充的中性色按钮。
- 圆角要温和，不要玩具感。
- hover 动效控制在 `120ms` 到 `220ms` 之间。

### 商品或内容网格

- 图片比例保持一致，但可以偶尔打破秩序，插入一个更具编辑感的放大项。
- 文本标签保持紧凑。
- 价格、材质、规格等信息应弱于名称和造型。

### 抽屉与菜单

- 覆层要轻、透、分层明确。
- 使用大块留白、清晰分组、必要时加入缩略图。
- 避免厚重阴影和过于硬朗的模态框边缘。

## 动效

动效应当克制到几乎注意不到，但又能提升质感。

- 适合使用淡入、遮罩显现、轻微视差、顺序出现。
- 缓动优先柔和成熟，例如 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 避免弹跳、过强缩放、悬浮漂移、炫技滚动特效。
- 最强的动效只留给首屏揭示、菜单切换、图像切换。

推荐动效 token：

```css
:root {
  --ease-luxury: cubic-bezier(0.22, 1, 0.36, 1);
  --dur-fast: 160ms;
  --dur-base: 280ms;
  --dur-slow: 520ms;
}
```

## 材质与细节

通过实现细节暗示工艺感，而不是靠显眼装饰。

- 使用边缘细线、内嵌分隔、柔和色块、图像裁切建立精度感。
- 如需纹理，只能非常轻，例如纸张颗粒、胶片噪点、亚麻雾感。
- 装饰图形必须抽象且稀疏。
- 容器、遮罩、裁切框可以呼应折线、曲面、包裹感。

## 文案语气

文案应当像编辑型品牌，不像强转化广告页。

- 用语简洁、含蓄、带感官性。
- 多使用与形体、材质、节奏、工艺、触感相关的名词和动词。
- 避免热血营销词、创业黑话、强烈催单话术。
- 让短句有呼吸感。

合适的文案方向示例：

- “由安静的流动塑造出的轮廓。”
- “一项关于曲线、折叠与平衡的研究。”
- “克制、可触、稳定，并且经久。”

## 面向 Codex 的执行要求

当 Codex 使用本 skill 进行页面实现时，应遵循以下流程：

1. 先提炼一套完整设计 token，再开始写结构和样式。
2. 先确定版式与图文节奏，再处理微交互和装饰。
3. 先移动端，再扩展到平板和桌面端。
4. 页面信息密度必须克制，移动端也不能拥挤成普通卡片流。
5. 优先使用语义化结构，保证可访问性与可读性。
6. 所有颜色、间距、字号、圆角、动效时长尽量通过变量统一管理。
7. 如果现有项目已有设计系统，优先继承其结构，再用本 skill 的气质规则做调整。

## React 实现建议

如果在 React 中实现：

- 按叙事角色拆分组件，例如 `Hero`、`EditorialSplit`、`CollectionGrid`、`MaterialStory`、`Footer`。
- 状态保持轻量、局部，不要为了样式切换制造复杂状态树。
- 优先使用 CSS 变量和组合结构，不要堆过多样式分支 props。
- 过渡动效用于内容切换，而不是让页面一直在动。
- 大图资源使用懒加载，首屏图优先加载。

## Tailwind 实现建议

如果在 Tailwind 中实现：

- 先扩展主题 token，不要到处堆任意值。
- 抽出可复用的编辑式容器、细分隔线、展示字体等 utility 组合。
- 少用阴影、亮色背景和高饱和 ring。

## 输出质量检查

交付前自查：

- 页面是否在不依赖金色、高光、复杂装饰的前提下仍显得高级？
- 留白是否足够，让内容显得从容？
- 图片是否像被策划过，而不是随手插入？
- 字体是否同时承担了气质和层级？
- 动效是否克制到只有细看才意识到？
- 如果去掉图标、徽章、花纹，页面是否仍然成立？

只要有一项答案是否定的，就继续简化并重排。

## 默认页面结构

除非当前项目已有明确内容结构，否则默认按以下顺序组织新页面：

1. 克制的顶部导航
2. 编辑感首屏
3. 一段简短品牌陈述
4. 图片主导的内容或商品网格
5. 材质、工艺或理念分栏区
6. 节制的行动引导区
7. 安静的页脚

## 禁止事项

不要产出以下结果：

- 黑金堆叠、镜面高光、浮夸奢华符号
- 标准创业公司官网式大图标加功能列表
- 用高密度信息假装高级的页面
- 过度滚动动画和炫技转场
- 在每个区域都使用过亮的主按钮
- 没有材质逻辑的随机强调色
- 默认系统字体直接铺满页面导致品牌感消失

## 灵感关键词

在需要快速校准方向时，优先回到这些关键词：

- 雕塑感曲线
- 编辑式留白
- 暖中性色高级感
- 以小见大的精确细节
- 有机轮廓与克制秩序
- 安静，但不平庸
